# dot 라이브러리

dot 은 정보를 주고받기 위해 문자열 전용 data tree 구조이다. 의존노드(자식노드)가 단수인 경우 . 으로 복수인 경우는 lisp 처럼 ( , ) 형태로 의존을 표현한다.

```
예:
a
  -> b
  -> c

=> a(b,c)

a
  -> b
    -> b1
  -> c
    -> c1
    -> c2

=> a(b.b1, c(c1,c2))
```

기능적으론 json의 서브셋으로서 다음과 같은 특징을 갖는다.

- 모든 데이터 타입은 string 이다.
- dot 은 key-value 구조를 지원하지 안는다. 대신 value 를 key의 하위 노드로 생성한다.
- 배열은 빈 문자열의 하위 노드로 생성된다.

이 규칙을 통해 json 으로 json 을 dot 으로 표현하되 모든 숫자는 문자열로 변환되며 이 변화는 비가역적이다.

```
예:

  {
    'name':'kwak ju hyun'
    'age':16
    'birth':'1972-08-28'
  }

  => (name.kwak ju hyun,age.16,birth.1972-0828)
```
